  Measured by cross-compiling and reading the object file's sections,
  which is the accounting a firmware engineer does. Code is roughly as
  large as the tables it reads, so a flash figure counting only tables --
  which is what the modelled budget reports -- is short by about half.
  The Cortex-M0+ row is the honest answer to whether this runs on a part
  without an FPU: it does, and every float becomes a library call.

  Instructions, not cycles: QEMU models no pipeline, no flash wait
  states and no memory system, so real silicon will take at least this
  many and generally more. The modelled figure alongside is lower still,
  which is worth knowing before sizing a task period from it.
