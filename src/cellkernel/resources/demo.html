01 / The estimation loop

Use physics to predict. Use voltage to correct.

  1. A small model tracks lithium moving inside the battery.
  2. An extended Kalman filter compares predicted voltage with a noisy measurement.
  3. It adjusts the estimated charge and repeats every second.

What this proves: recovery under controlled starting errors and noise. The same model creates the synthetic measurements, so this does not establish accuracy on an actual cell. The measured-data ML comparison is a separate experiment in the repository.
